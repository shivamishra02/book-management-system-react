# Book Management System

A React-based Book Management System with full CRUD functionality using MockAPI.

## Features

* Add Books
* Update Books
* Delete Books
* Search Books
* Filter by Genre
* API Integration using MockAPI
* Responsive UI

## Tech Stack

* React.js
* Vite
* Axios
* CSS
* MockAPI

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/shivamishra02/book-management-system-react.git
```

### Navigate to Project Folder

```bash
cd book-management-system-react
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Open in Browser

```bash
http://localhost:5173
```
